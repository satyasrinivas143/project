Database Management Systems – Mini Project
Project Abstract
MySpendMate
Secure Student Money Management System
Overall Abstract

MySpendMate is a full-stack web application that helps students organize personal finances through income and expense tracking, category-based budgeting, savings goals, and visual reports. Because financial records are personal, the application provides account registration, email-and-password login, profile management, and logout. Passwords are stored as salted scrypt hashes, and an HTTP-only session cookie is used to maintain a signed-in session.

The frontend is built with HTML, CSS, and JavaScript, while a Node.js and Express backend provides a JSON API and stores accounts, profiles, and financial records in SQLite. Database queries scope each user's records to their account, and browser-side cached data is kept under account-specific keys. The dashboard and reports summarize recorded transactions and goals with interactive charts, helping students understand their cash flow and make informed budgeting decisions. New installations start with an empty database; old shared demo data is not imported.

Project Objectives
  • Track student income and expenses in one application.
  • Create and update budgets according to different spending categories.
  • Monitor saving progress for academic and personal goals.
  • Generate clear visual reports for better financial analysis.
  • Allow students to register, log in, manage profile details, and log out.
  • Keep financial records and browser caches separated by account.
  • Demonstrate database-backed record management through a responsive web interface.

Module-wise Overview
Module Purpose Functionality
1 Dashboard Module Summarizes the signed-in user's recorded income, expenses, budgets, and savings goals with charts and recent activity.
2 Budget Planner Module Creates category-based budget limits and compares planned amounts with recorded spending.
3 Expense Module Records, searches, sorts, and deletes the user's expense transactions.
4 Income Module Maintains income transactions and user-defined sources such as scholarships, employment, and family support.
5 Savings Goal Module Creates savings goals, sets target amounts and deadlines, and tracks contributions and progress.
6 Reports & Analytics Module Visualizes account-specific transaction history, income, expenses, savings, and spending categories.
7 Profile & Settings Module Registers and authenticates accounts, manages profile details, maintains login/logout sessions, and restricts financial data to its owner.
System Scope

The system covers account creation and authentication, profile updates, and the per-user management of income, expenses, budgets, savings goals, and reports. The Express API validates account and profile input, stores password hashes rather than plaintext passwords, and protects application endpoints with session authentication. SQLite stores user and finance records; each finance query is scoped to the authenticated account. New databases are initialized empty rather than populated with shared demo records. Browser storage provides an account-specific cache, while the backend database is the shared persistence layer.

Expected Outcome

MySpendMate provides a working, account-based platform where students can create an account, sign in, manage profile information, track their own financial records, and log out. Its dashboard and reports present summaries derived from the user's saved data, while SQLite persistence supports returning sessions and account-level separation. The project demonstrates practical DBMS concepts—including relational storage, validation, querying, and ownership-based data access—in a student finance application.
